MICROPROJECT DEMO WALKTHROUGH

Scanner Pipeline Architecture & Pseudocode

01 // INGEST

CSV + SQLite Extraction

Reads UTF-8 CSV headers/rows and queries SQLite sqlite_master + PRAGMA table_info.

02 // CLASSIFY

Multi-Signal Rule Scoring

Evaluates column regex + sample-value match ratio across 5 classes with configurable weights.

03 // JOIN

Metadata & Gap Audit

Joins candidate PII fields to declared purpose & retention schedules; flags missing entries.

04 // EVALUATE

Precision / Recall + Review

Compares predictions vs. ground truth and exports human-review evidence without legal rulings.

ALGORITHM PS019_Discover_And_Audit_Privacy_Evidence:
  INPUT:
    csv_files      ← read_all("data/csv/*.csv")
    sql_tables     ← query_sqlite("data/privacy_demo.db", PRAGMA table_info + SELECT *)
    rules          ← load_enabled_rules("data/rules.json")
    meta_registry  ← load_metadata("data/metadata_registry.json")
    ground_truth   ← load_ground_truth("data/ground_truth.json")

  STEP 1: SCAN_AND_CLASSIFY(sources, rules)
    FOR EACH (source_type, container, column, values) IN (csv_files + sql_tables):
      scores ← {}
      FOR EACH rule IN rules WHERE rule.enabled == TRUE:
        col_hit   ← regex_match(rule.column_pattern, column)
        val_ratio ← count(v IN non_null(values) WHERE regex_match(rule.value_pattern, v)) / len(non_null(values))
        score     ← (rule.column_weight IF col_hit ELSE 0) + (rule.value_weight * val_ratio IF val_ratio >= rule.min_value_match_ratio ELSE 0)
        IF score > 0:
          scores[rule.data_class] ← combine_confidence(scores[rule.data_class], min(score, 1.0))

      predicted_class ← argmax(scores) IF max(scores) >= 0.45 ELSE "NONE"
      masked_preview  ← mask_samples(values[:3], predicted_class)

  STEP 2: LINK_PURPOSE_AND_FLAG_EVIDENCE_GAPS(evidence, meta_registry)
    FOR EACH record IN evidence:
      meta ← meta_registry.get(record.field_key)
      IF record.predicted_class == "NONE" AND empty(meta.purpose) AND empty(meta.retention):
        record.gap_status ← "NOT_APPLICABLE"
      ELSE IF present(meta.purpose) AND present(meta.retention):
        record.gap_status ← "COMPLETE"
      ELSE:
        record.gap_status ← MISSING_PURPOSE | MISSING_RETENTION | MISSING_BOTH   # Flagged for human review

  STEP 3: EVALUATE_AGAINST_GROUND_TRUTH(evidence, ground_truth)
    FOR EACH class C IN [DIRECT_IDENTIFIER, NATIONAL_ID, FINANCIAL_INFO, CONTACT_LOCATION, SENSITIVE_ATTRIBUTE, NONE]:
      TP ← count(pred == C AND true == C)
      FP ← count(pred == C AND true != C)
      FN ← count(pred != C AND true == C)
      Precision[C] ← TP / (TP + FP);   Recall[C] ← TP / (TP + FN);   F1[C] ← 2*P*R / (P + R)

  OUTPUT:
    Evidence Inventory + Gap Report + Precision/Recall Metrics
    TAGGED: "Technical discovery evidence for human review; NOT a legal compliance decision."
